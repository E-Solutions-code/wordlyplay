## Features

- ♾️ **Unlimited Play** — No daily limit, play back-to-back
- ⚔️ **Multiplayer Battles** — Challenge friends or random opponents in real-time
- 📅 **Daily Challenge** — One shared puzzle for the global community
- ⏱️ **Timer Mode** — Solve against the clock
- 📊 **Leaderboards** — Daily, weekly, and monthly rankings
- 💎 **Power-ups** — Hints, reveals, and extra rows via gem system
- 🎯 **3 Difficulty Levels** — Easy, Medium, Hard
- 📱 **All Devices** — Desktop, tablet, mobile — no app download needed
